# SkyBEAT 🎵

## 1. 프로젝트 소개

SkyBEAT는 오늘의 추천곡, 신규 발매곡, 인기 아티스트와 기분별 음악 카드를 한 화면에서 살펴볼 수 있도록 구성한 음악 소개 사이트입니다. HTML과 Tailwind CSS로 메인 페이지와 로그인 페이지의 정적 화면을 구현했습니다.

| 항목 | 내용 |
| --- | --- |
| 사이트 구성 | 추천곡, 신규 발매곡, 인기 아티스트, 기분·테마별 음악 카드, 로그인 화면 |
| 화면 콘셉트 | 하늘색 계열의 색상, 앨범 커버 중심의 카드, 기분과 테마를 나타내는 해시태그 |
| 제작 목적 및 기획 의도 | SkyBEAT는 추천곡과 신규 발매곡, 장르별 음악등 웹사이트입니다. 음악을 직접 재생하기보다는, 관심 있는 음악을 발견하고 외부 음악 서비스로 이동하는 방향으로 기획했습니다.  |

곡 정보와 아티스트 목록은 HTML에 직접 작성되어 있습니다. JavaScript, 음악 API, 백엔드 및 로그인 인증 기능은 구현되어 있지 않습니다.

## 5. 반응형 구현

실제 분기점은 Tailwind의 `md`(`48rem`)와 `xl`(`80rem`)입니다. 아래 픽셀 값은 기본 글자 크기 16px 기준이며, 기기 종류가 아닌 화면 너비에 따라 적용됩니다.

| 영역 | 모바일: 768px 미만 | 태블릿·중간 화면: 768px 이상, 1280px 미만 | 넓은 PC 화면: 1280px 이상 |
| --- | --- | --- | --- |
| 헤더 | 로고와 햄버거 버튼 표시, 검색·로그인·회원가입·메뉴 숨김 | 검색·로그인·회원가입·가로 메뉴 표시, 햄버거 숨김 | 중간 화면과 동일하며 바깥쪽 좌우 여백 조정 |
| 추천곡 | 이미지와 설명을 세로로 배치 | 이미지와 설명을 가로로 배치 | 가로 배치 유지 |
| 신규 발매곡 | 3열 유지 | 3열 유지 | 3열 유지 |
| 인기 아티스트 | 1열, 카드 비율 3:1 | 6칸 Grid에서 위쪽 2개는 각각 3칸, 아래쪽 3개는 각각 2칸 사용 | 동일한 2개·3개 배치 유지 |
| 테마 카드 | 2열 | 4열 | 4열 |
| 푸터 하단 | 로고·저작권·SNS 세로 배치 | 가로 배치 | 가로 배치 유지 |
| 로그인 | 최대 너비 안에서 화면 폭에 맞춤 | 로고와 폼 사이 간격 및 폼 위아래 여백 증가 | 중간 화면과 동일 |
| 공통 콘텐츠 | 섹션 좌우 여백 적용 | 섹션 좌우 여백 유지 | `.content-inner`에 최대 너비 `80rem` 적용, 가운데 정렬 |

인기 아티스트의 아래쪽 3개 카드는 `md` 이상에서 비율이 2:1로 바뀝니다. 공통 섹션 제목은 기본 20px, `md` 이상 22px, `xl` 이상 24px로 커집니다. 모바일 햄버거는 표시만 구현되어 있어 숨겨진 메뉴를 펼칠 수 없습니다.

## 6. 디자인 시스템 및 공통 스타일

### 색상과 디자인 토큰

`style/input.css`에서 `@soyen98/project1-token/tailwind`를 가져와 의미별 색상 클래스와 간격, 모서리 값을 공유합니다.

| 사용 예 | 색상 | 적용 위치 |
| --- | --- | --- |
| `brand-primary`, `text-brand`, `border-default` | `#4ab4ff` | 기본 버튼 배경, 강조 글자, 테두리 |
| `brand-primary-hover` | `#0d619d` | 버튼 hover 배경 |
| `brand-soft`, `skyblue-100` | `#cce1f4` | 추천곡 및 인기 아티스트 배경 |
| `text-accent`, `brand-secondary` | `#0873bf` | 곡 부가 정보, 테마 스타일 |
| `text-accent-strong`, `skyblue-900` | `#20354f` | 제목과 푸터 배경 |
| `Ivory` | `#f2f3f8` | 메인 페이지 전체 배경 |
| `text-secondary` | `#9e9e9e` | 카드 설명 등 보조 글자 |

### 폰트와 재사용 스타일

별도의 웹폰트를 불러오는 코드나 `font-primary` 적용은 없습니다. 화면은 Tailwind 기본 sans-serif 글꼴 구성을 사용하며, 제목·본문·설명의 크기와 굵기를 클래스로 조정합니다. `font.css`는 폰트 파일을 불러오는 대신 공통 제목 `.title`을 정의합니다.

공통 CSS는 `@layer components`와 `@apply`로 정의하고 `style/input.css`에서 모아 불러옵니다.

| 구분 | 공통 클래스 | 구현 내용 |
| --- | --- | --- |
| 레이아웃 | `.content-spacing`, `.content-inner` | 섹션 여백, 가운데 정렬, PC 최대 너비 |
| 제목 | `.title` | 강조 색상, 굵기, 반응형 글자 크기 |
| 버튼 | `.btn`, `.btn-light`, `.btn-dark`, `.btn-dark-wide`, `.btn-full` | 기본·테두리·배경형 버튼, 너비와 여백 변형, hover·focus 효과 |
| 카드 | `.card`, `.card-image`, `.card-title`, `.card-artist`, `.card-description` | 이미지 비율, 텍스트 계층, 설명 두 줄 제한, 이동·확대 효과 |
| 뱃지 | `.badge`, `.badge-light`, `.badge-dark` | 둥근 태그, 테두리형과 배경형 구분 |
| 테마 버튼 | `.hashtag`, `.hashtag-off`, `.hashtag-on` | 기본·활성 스타일 정의, hover·focus 효과 |

테마 버튼의 `.hashtag-on` 스타일은 정의되어 있지만, 현재 HTML의 테마 버튼은 모두 `.hashtag-off`이며 상태 전환 로직은 없습니다. 공통 음악 카드에는 `motion-reduce`로 이동·확대 효과를 줄이는 스타일이 적용되어 있습니다.

│   ├── input.css           # CSS 빌드 진입점
│   └── output.css          # 빌드된 CSS
├── index.html              # 메인 페이지

`main-page.html`은 현재 존재하지 않는 `dist/output.css`를 참조합니다. 화면 확인은 `style/output.css`가 연결된 `index.html`과 `login.html`을 기준으로 합니다.

## 8. 실행 방법

### 1. 개발 환경 준비 및 패키지 설치

Node.js와 npm을 설치한 뒤, VS Code에서 프로젝트 폴더를 엽니다.
프로젝트 루트의 터미널에서 필요한 패키지를 설치합니다.

```sh
npm install
```

Tailwind CSS를 별도로 설치해야 하는 경우 다음 명령어를 실행합니다.

```sh
npm install tailwindcss @tailwindcss/cli
```

### 2. Tailwind CSS 실행

개발 중 파일 변경 사항을 CSS에 반영하려면 감시 모드를 실행합니다.

```sh
npx @tailwindcss/cli -i ./style/input.css -o ./style/output.css --watch
```

스타일은 `style/input.css`와 `style/components/`에서 수정합니다.
`style/output.css`는 자동으로 생성되는 파일입니다.

한 번만 빌드하려면 다음 명령어를 실행합니다.

```sh
npx @tailwindcss/cli -i ./style/input.css -o ./style/output.css
```

### 3. 화면 확인

VS Code에서 `index.html`을 우클릭한 뒤 **Open with Live Server**를 선택합니다.
로그인 화면은 메인 페이지 상단의 로그인 링크를 통해 확인할 수 있습니다.

Live Server가 5501 포트로 실행된 경우 접속 주소는 다음과 같습니다.

- 메인 페이지: http://127.0.0.1:5501/index.html
- 로그인 페이지: http://127.0.0.1:5501/login.html

실제 접속 주소는 Live Server 실행 시 열린 브라우저에서 확인합니다.

### 참고 사항

- Tailwind 감시 모드와 Live Server는 각각 실행해야 합니다.
- 저장소에 `style/output.css`가 포함되어 있어 기존 화면만 확인할 때는 설치나 빌드 없이 HTML 파일을 열 수 있습니다.
- 외부 URL을 사용하는 이미지는 인터넷 연결 및 이미지 제공 서버 상태에 따라 표시되지 않을 수 있습니다.

## 9. 협업 및 문제 해결

### 확인 가능한 협업 내용

| 항목 | 확인 내용 |
